# 提取词汇之外的文风

词汇首先形成语言身份、关系距离和语域，但它不是全部。相同词汇经过不同语序、断句、段落展开和整篇顺序，会形成完全不同的声音。本页负责把这些选择提取成可观察、可复核、可迁移的档案。开始标注前完整读取 [four-layer-writing-contract.md](four-layer-writing-contract.md)：它只规定必须检查的维度，不提供应当采用的句型、骨架或全文路线。

## 两张分析地图

第一张地图按文字大小分层：

```text
词汇选择 → 句式构造 → 段落结构 → 整篇编排
```

词汇由 `lexical-extraction.md` 处理。本页分别提取后面三层。节奏、叙述声音、情绪、具体程度、修辞、标点和排版不是第五种文字大小，而是横跨句子、段落和整篇的观察维度。

第二张地图按判断过程分层：

```text
可观察写法 → 推定阅读效果 → 稳定组合 → 场景适用性
```

“短句”“第二人称”“段首先给结论”属于可观察写法；“快速、亲近、直接”属于推定效果；“中句解释 + 短句收束 + 普通场景协商、高风险场景禁止”才可能构成稳定声音。不能从一个词、一个标点或一句典型文本直接跳到文风名称。

## 先记录证据再判断效果

每个维度使用同一记录格式：

```text
维度：
适用性：适用／不适用／证据不足
主倾向：
次倾向：
可观察证据：次数、比例、长度、位置、覆盖、原文上下文
实际功能：
推定阅读效果：
可能混淆因素：题材、场景、媒介、文体默认、单章集中等
对照差异：
场景变化：
可迁移性：
置信度：
```

适用性必须显式记录。纯对白可能没有页面排版证据，操作说明可能没有叙事距离，短消息可能无法证明整篇结构。没有证据时标为“不适用”或“证据不足”，不能补一个看起来完整的答案。

统计值只描述表面分布。反问是否施压、主语省略是否隐藏责任、留白是否仍能理解、幽默来自哪里，都必须回看固定样本。

## 句式档案

### 句法和焦点

至少检查：

- 主语是否出现；出现时放在句首、句中还是判断之后；
- 责任主体是否清楚，还是被无主句、被动句或抽象名词隐藏；
- 主动、被动、判断、定义、把字、祈使、省略和碎片句怎样分布；
- 条件、时间、风险、对象、原因或结论是否经常提前；
- 重点落在句首、句尾、插入语、括号、破折号还是独立短句；
- 并列、从属、让步、因果、比较和纠正结构怎样组合；
- 完整句与省略句分别在什么场景出现。

不要用“短句就是口语、长句就是专业、被动句就是正式”这类固定映射。相同句长可以承担命令、结论、笑点或文学停顿，必须记录功能。

### 言语行为与关系

句式还要回答“这句话正在做什么”。标注：

- 告知、询问、确认、建议、请求、要求、禁止、拒绝、承诺、道歉、安抚或邀请行动；
- 开放疑问、一般疑问、选择问、确认问和反问；
- 直接说出意图，还是理由前置、暗示、让步后转向或通过反问施压；
- 是否解释原因，是否给对方选择，是否写出安全替代；
- 如何处理异议：承认一部分、重设范围、给证据、否定、回避或攻击；
- 高风险或不可逆场景中，行动压力怎样升级。

礼貌、判断确定性和行动压力是三个轴。“请务必停止”有礼貌但行动压力很高；“原因还不能确定，但必须先停机”判断保留却仍是明确命令。

### 长度、节奏和停顿

报告平均句长之外，还要给出中位数、P75、P90、标准差或变异程度，并在段落内部观察相邻句长变化。检查：

- 连续短句通常承担结论、命令、紧张、反转还是笑点；
- 长句承担条件链、背景、机制还是情绪累积；
- 是否存在稳定的“长分析—短结论”“短行动—长解释”或其他交替；
- 逗号、句号、分号、省略号、破折号和括号怎样分配停顿；
- 重复、平行和故意断裂是在强调、安抚、推进还是制造反差。

## 段落档案

段落是一个主要任务加完成该任务所需的辅助材料，不是固定三句模板。逐段标注：

1. **段首怎样进入**：结论、问题、事实、场景、定义或承接前文；
2. **中间怎样展开**：原因、证据、例子、步骤、对比、分类、条件、反例或回应异议；
3. **段尾怎样退出**：小结、判断、行动、限制、悬念或转向；
4. **整体骨架**：例如结论—原因—行动、观点—解释—例子、问题—原因—方案、事实—影响—判断、场景—变化—含义；
5. **怎样拆段**：按话题、行动阶段、时间、说话者、场景或重点变化；
6. **怎样过渡**：依靠内容复现、因果、对比或问题承接，还是机械插入“首先、其次、总之”；
7. **怎样排版**：自然段、单句段、列表、表格、引用和提示框分别承担什么关系。

每段只统计长度还不够。要说明段首、展开和段尾各自做了什么，以及这种骨架是否跨样本重复。列表只能证明信息被分行，不能自动证明逻辑清楚。

## 整篇编排档案

整篇编排回答读者先知道什么、后知道什么。它与内容模型不同：内容模型规定必须保留哪些事实，编排档案记录相近任务中稳定偏好的呈现顺序。

逐篇标注：

- 文本用途、主要读者和读者打开文本后的首要问题；
- 答案、结论、异常、场景或背景最先出现；
- 背景放在开头、解释段、需要时插入还是附录；
- 证据、例子、反例、限制和行动分别放在什么位置；
- 使用答案先行、问题解决、教程流程、比较选择、观点论证、案例归纳、总分、时间顺序或悬念推进中的哪一类路线；
- 解释下钻到结论、原因、机制、例子、边界、反例和步骤中的哪一层；
- 结尾交付结论、行动、责任主体、成功标志、失败恢复、余味还是新问题。

只有相近文体、读者和目的的文本可以比较整篇顺序。小说的悬念后置不能直接迁移到安全说明；技术文档的答案先行也不能证明叙事文本缺少风格。

## 阅读效果轴

完成可观察标注后，再推定读者可能感受到什么。下面各轴互相独立，不能压成一个“语气”或一个一到五分总分。

| 组 | 必须分开的轴 | 主要证据 |
| --- | --- | --- |
| 关系 | 正式程度、关系距离、权力位置 | 人称、称呼、语域、句子完整度、命令方式、是否解释原因 |
| 判断与行动 | 确定程度、行动压力、直接程度、判断归属 | 情态词、证据来源、祈使和禁止、理由位置、主语与责任 |
| 情绪 | 正负方向、情绪强度、对读者的冷暖、情绪是否直说 | 评价词、程度词、动作、停顿、感叹、安抚和留白 |
| 信息 | 抽象或具体、模糊或精确、信息密度、逻辑显化、展开深度 | 场景、数字、范围、术语、因果、例子、步骤和边界 |
| 节奏与表现 | 阅读速度、停顿强度、互动程度、修辞密度 | 句长变化、标点、换行、第二人称、设问、比喻和重复 |

每个效果判断写出支持证据和反证。例如“使用您”可能提高正式度，却不能单独证明温暖；短句可能加快速度，也可能形成冷淡、命令或文学停顿。需要验证单个特征时，保持事实和其他写法不变，只改变一个变量，再检查效果是否随之改变。

## 声音与表现策略

除四层结构外，还要检查横跨全文的选择：

- 叙述视角和距离：谁在说、谁知道、离人物意识或读者多近；
- 具体程度和精确程度：是否从抽象判断落到动作、物件、数字、范围和感官；
- 信息密度和留白：单位长度有多少新信息，省略后是否仍留下推断依据；
- 重复和修辞：关键词、句首、回环、对比、比喻、排比、反转和反讽承担什么作用；
- 标点和排版：句号、问号、感叹号、省略号、破折号、括号、标题、列表和表格怎样组织阅读；
- 互动与幽默：是否预判疑问、邀请行动；笑点来自反差、降格、延迟、三段式还是回调；
- 叙事时间：顺叙、倒叙、压缩、延展、现在时或回顾怎样改变信息释放。

文学文本可以使用留白和叙事距离；工作文档通常需要降低歧义。不要把适合来源场景的省略、错误、价值立场或人物选择直接迁移到事实说明、代码和安全边界。

## 一致性与场景变化

声音一致不等于每句话相同。每个稳定维度记录：

- **主倾向**：最常见、跨样本稳定的选择；
- **次倾向**：真实存在但使用较少的备用方式；
- **变化触发条件**：风险、关系、媒介、情绪、文本用途或叙事阶段怎样触发变化；
- **保持不变的组合**：即使场景变化，哪些词汇关系、节奏或信息习惯仍在；
- **禁用项**：哪些词、标点、结构和情绪方式稳定缺席；
- **不可迁移项**：来源人物的价值立场、世界观、事实错误、情节选择和题材内容。

真正的声音指纹通常只需要三到五组稳定组合。孤立特征、文体默认结构、单场景爆发和题材专词不能进入核心指纹。

## 采样标注与验证

大语料先固定种子采样 100–300 个有效段落，并覆盖前中后位置、不同文档、说话场景和情绪强度。再保留未参与规则发现的样本，用于检查规则能否复现。

执行顺序：

1. 用脚本取得句长、段长、标点、句型候选、段落形状、词类覆盖和组合共现等机械指标；
2. 在固定样本上人工标注言语行为、责任主体、焦点位置、段落开中尾功能和整篇路线；
3. 与相邻作者、说话者、团队或同文体材料比较，排除语言共有特征；
4. 检查规则在全文、独立单元和保留样本中是否方向一致；
5. 将结论标为“稳定”“场景限定”“暂定”或“否决”，并说明原因；
6. 用同一事实制作单变量对照和完整前向生成，分别检验局部归因与整体声音；
7. 检查生成文本是否保留事实、责任、安全边界和目标读者需要，且没有来源身份泄漏。

不要预设通用词频、句长或覆盖率门槛。阈值应随语料规模、文体和特征稀有度确定；低频修辞与高频功能词不能使用同一标准。
