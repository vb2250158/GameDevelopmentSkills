# 具体文章样本：段落、句式与词语复现

本页记录的是已阅读样本的结构观察，不保存或复写原文。网页上的“优秀范文”不等于可核验的满分卷：高考考生答卷和评阅情况原则上不公开。把它们作为写法样本，不把标题当成质量保证。

## 先用样本，后用规则

每次借用样本时，记录五件事：

1. 题目要求回答的关系，而不只是主题词；
2. 每段在全文中的功能；
3. 本段反复出现的核心词、动词和连接词；
4. 例子之后如何回到判断；
5. 这套写法适合什么文体，迁移到当前任务会不会显得空泛或夸张。

小样本只能帮助观察“词如何工作”，不能得出中文总体词频，也不能把某些口头禅当成高质量标志。

## 已读长文样本

### 1. 上海卷“好奇心与探索”范文：必要条件不等于充分条件

- **来源与性质**：[中国教育在线整理的 2023 上海卷优秀范文](https://gaokao.eol.cn/zuowen/jiqiao/202401/t20240118_2555434.shtml)。网页标为范文，未提供真实评分证明。
- **题目关系**：探索陌生世界是否仅由好奇心驱动。
- **段落路线**：提出关系 → 证明好奇心是动力 → 用“然而”提出不足 → 加入努力、坚持、勇气等条件 → 收束为两者相互配合。
- **词语系统**：高频锚点是“好奇心、探索、陌生世界”；第二组为“努力、风险、坚持、勇气”。第一组让读者不丢题，第二组完成转折后的新判断。
- **可学之处**：反复的不是空洞形容词，而是题目中的概念；转折段改变了文章的判断层级。
- **不要照搬**：连续罗列名人或用抒情短句替代分析，在技术说明中会稀释证据。

### 2. 新课标 II 卷“自己的空间”范文：正面论证后补边界

- **来源与性质**：[中国教育在线整理的 2023 新课标 II 卷优秀范文](https://gaokao.eol.cn/zuowen/jiqiao/202401/t20240118_2555416.shtml)。网页标为范文，未提供真实评分证明。
- **题目关系**：青少年需要独处空间，但这种空间与成长、社会联系怎样相处。
- **段落路线**：空间的必要性 → 独处如何促成自省 → “当然”引出限制：独处不等于隔绝 → 将自我与世界重新合并。
- **词语系统**：反复锚点为“空间”；成对词为“自我／世界”“独处／入世”。一对词制造全篇张力，连接词“当然”负责从肯定转向限制。
- **可学之处**：先充分承认一个主张，再写它的边界，最后给出兼容的结论；这种结构适合复杂问题、方案权衡和科普风险说明。
- **不要照搬**：过多典故会让证据链看似丰富、实则难以核验。

### 3. 新课标 I 卷“故事的力量”范文：同一核心词跨尺度推进

- **来源与性质**：[中国教育在线整理的 2023 新课标 I 卷优秀范文](https://gaokao.eol.cn/zuowen/jiqiao/202401/t20240118_2555413.shtml)。网页标为范文，未提供真实评分证明。
- **题目关系**：好故事如何表达、沟通、触动人与呈现群体形象。
- **段落路线**：故事源于生活 → 个人与文明的传承 → 当下的创造 → 更大范围的传播与共享 → 回到“故事”的意义。
- **词语系统**：反复锚点为“故事”；配套动词是“创造、传承、传播”。名词不变、动词递进，能让篇章向前走，而不是原地重复。
- **可学之处**：一个核心名词配一组方向不同的动词，可以形成段落分工。
- **不要照搬**：从个人直接跳到民族、世界等大尺度，若没有中间证据，容易变成宏大但松散的抒情。

### 4. 北京卷“续航”范文：定义、追问、分层回答

- **来源与性质**：[中国教育在线整理的 2023 北京卷优秀范文](https://gaokao.eol.cn/zuowen/jiqiao/202401/t20240118_2555432.shtml)。网页标为范文，未提供真实评分证明。
- **题目关系**：为抽象词“续航”重新赋义并展开论证。
- **段落路线**：界定概念 → 提出“如何做”的问题 → 个人层面 → 集体层面 → 再次收束。
- **词语系统**：反复锚点是“续航”；“个人／集体”承担分层；“为什么／如何”把读者从定义带到行动。
- **可学之处**：解释抽象概念时，先给工作定义，再用问题切换到方案。
- **不要照搬**：同一词如果每句都出现，且没有新的谓语或新关系，就会显得口号化；词语复现必须带来新的信息。

### 5. 模拟题“眼光与境界”范文：意象与排比的收益和代价

- **来源与性质**：[中国教育在线 2024 模拟题例文](https://gaokao.eol.cn/zuowen/jiqiao/202405/t20240524_2611975.shtml)，不是高考考生原卷。
- **段落路线**：从材料引出看法 → 写旧书 → 写新文化 → 用比喻收束“眼光” → 倡议式结尾。
- **词语系统**：围绕“眼光、新旧、世界”反复，句法常用并列、设问和比喻。
- **可学之处**：感性散文可以让同一意象在开头、中段、结尾回环，形成声音与画面上的统一。
- **不要照搬**：它的因果分析较少。面对技术、政策或方案问题，必须补上事实、机制和条件，不能只靠意象推进。

## 短文答案样本应怎样读

阅读题的答案与作文相反：词汇追求准确复用，而不是风格新奇。可参考 [2024 年新课标 II 卷参考答案](https://gaokao.eol.cn/shiti/yw/202406/t20240613_2616371_1.shtml) 观察其常见做法：一条要点只回答一个作用或关系；用“整体上、具体地、通过”标明观察角度；将文本事实和其表达效果连在同一句里。

把短答写成下列骨架即可，词汇按原材料替换：

> 这一处先写出【文本事实】；随后通过【手法或关系】表现【直接效果】，并在全文中起到【结构或主题作用】。

这里的“先写出、通过、表现、起到”是功能动词。它们比生僻形容词更常出现，因为它们清楚标记了答案正在完成什么。

## 词频要看“位置 + 搭配 + 功能”

不要单独统计“高级词”出现次数。按下表观察一篇文章：

| 位置 | 应观察的词 | 它们的任务 |
| --- | --- | --- |
| 开头 | 题目核心名词、定义动词、判断词 | 建立讨论对象和立场 |
| 主体段首 | 分论点动词、范围词、转折词 | 告知本段的新任务 |
| 例子之后 | 因果词、解释动词、限定词 | 把材料推回论点 |
| 段落之间 | 然而、同时、进一步、因此等关系词 | 标注真正的推进或转向 |
| 结尾 | 核心词的回扣、行动或判断动词 | 收束而不重复全文 |

可接受的复现，是同一核心词在每次出现时增加了范围、条件、动作或结论。不可接受的复现，是只把同一句式、形容词或口号换序重说。
