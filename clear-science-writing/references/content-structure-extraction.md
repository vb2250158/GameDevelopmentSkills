# 提取内容与表达结构

这份参考把原始材料转成可写、可核查、可安排的内容结构。先分开两件事：内容模型回答“说什么、哪些事实不能改变”，内容编排回答“这些内容按什么顺序让读者理解”。分析阶段先隔离两者，交付阶段再用目标文风写出提取结果。

## 先继承语料语言

内容提取默认沿用语料的主要语言：

- 中文原文使用中文字段内容、判断、证据说明和段落地图。
- 英文原文使用英文，不先翻成中文分析再交付中文提取件。
- 混合语料按语言分组；明确的目标语料决定输出语言。没有明确主次且语言选择会改变用途时，只确认这一项。
- 用户明确要求翻译或双语时再切换。专名、代码、文件路径、标识符和必要引语不做无意义翻译。

内容卡与段落地图是交付物的一部分。先准确提取，待 `style-extraction.md` 生成目标文风后，再把这些文档的标题、说明、判断和衔接语重写成目标文风。表格字段可以为稳定含义保留结构，但字段名称也应使用目标语言；不要输出中英并列模板，除非用户要求双语。

## 输入材料先分层

将材料中的内容分为四类：

| 类别 | 要提取什么 | 写作时怎样使用 |
| --- | --- | --- |
| 事实 | 已发生的事、数据、原文表述、时间和责任主体 | 作为可核查的基础 |
| 判断 | 作者或材料得出的解释、立场、结论 | 写明依据和适用范围 |
| 证据 | 事例、数据、引语、机制和反例 | 用来支撑某一判断 |
| 未知 | 缺失的信息、争议、前提和例外 | 作为限制或待确认项 |

不要把“材料提到”误当成“材料已经证明”，也不要把猜测补成事实。

## 先写内容卡

在动笔前填完下表；缺失项保留为空或标为待确认，不补写。

| 字段 | 内容 |
| --- | --- |
| 读者与任务 | 谁需要读完后理解、判断或行动什么？ |
| 读者首要问题 | 读者打开文本后最先需要得到什么答案？ |
| 中心问题 | 文章实际要回答的一句话问题 |
| 核心判断 | 一句可独立成立、可被材料支持的答案 |
| 必须保留 | 事实、术语、责任主体、限制和已有结论 |
| 可删或后置 | 重复背景、旁支材料、不能支撑判断的细节 |
| 证据缺口 | 还缺什么才能把判断说得更确定？ |
| 结尾合同 | 结尾必须给出结论、行动、成功标志、失败处理、责任主体还是叙事余味？ |

## 再画段落地图

每段只承担一个主要动作，可以带完成该动作所需的证据、例子或条件。用下表规划全文，而不是照原材料顺序转述：

| 段 | 本段动作 | 本段判断或信息 | 依据 | 与下一段的关系 |
| --- | --- | --- | --- | --- |
| 1 | 提出问题或结论 |  |  | 引出原因／展开 |
| 2 | 解释原因或背景 |  |  | 因果／递进 |
| 3 | 给出证据或机制 |  |  | 例证／对比 |
| 4 | 补充条件或反例 |  |  | 转折／限制 |
| 5 | 收束意义或行动 |  |  | 回扣中心 |

段落地图是可变的：操作说明不需要“反例段”，短答可以只保留“答案—依据—结果”三项。每一段都要让读者获得新信息，不能只换词重复中心判断。

为重要段落补充三项标注：

- **怎样进入**：结论、问题、事实、场景，还是承接前文；
- **怎样展开**：原因、证据、例子、步骤、对比、分类、条件或回应异议；
- **怎样退出**：小结、判断、行动、限制、悬念或转向。

不要把“每段三句话”当成规则。段落边界应跟随话题、行动阶段、时间、说话者或场景变化；同一条连续推理不能只因句子较长就被切断。

## 单独填写整篇编排卡

内容卡确定材料，整篇编排卡确定理解顺序：

| 字段 | 内容 |
| --- | --- |
| 文本用途 | 回答、教程、排错、比较、论证、决策、复盘、通知或叙事 |
| 首个答案位置 | 首句、首段、背景之后、证据之后或揭示处；为什么 |
| 选用路线 | 答案先行、问题解决、背景到决策、教程流程、观点论证、比较选择、案例归纳、总分、时间顺序或悬念推进 |
| 背景位置与深度 | 哪些背景必须前置，哪些放在解释段或附录 |
| 证据安排 | 每项证据、例子和反例分别支持、排除或限制什么判断 |
| 结尾交付 | 结论、下一步、责任主体、成功标志、失败恢复或叙事余味 |

路线只描述信息顺序，不自动成为目标文风。只有同类文本跨样本持续选择同一种顺序时，才能把它写进语言风格档案；安全说明、操作文档和事实边界仍优先服从当前任务。

## 用关系而不是素材堆砌组织内容

选择真实存在的关系：

- **因果**：前提导致结果；先后发生不等于因果。
- **递进**：后一段比前一段多解释一个层次或扩大一个范围。
- **对比**：对象处于同一维度，比较结果服务判断。
- **转折**：前一判断仍成立，但需要加入条件、例外或反面。
- **总分**：先给全局判断，再分别解释其组成部分。

只有读者需要理解这个关系时，才显式使用“因此、但是、同时、进一步”等词。连接词不是结构本身。

## 输出给起草阶段的最小交接件

将提取结果压成以下格式，再开始写正文：

```text
内容任务：
读者首要问题：
中心判断：
读者已知／需要知道：
必须保留的事实与边界：
选用的整篇路线与理由：
答案位置与背景位置：
段落地图：
结尾合同：
待确认项：
```

这份交接件只规定内容与结构；文风另从 `style-extraction.md` 提取和绑定。绑定完成后，重新渲染交接件，使它与最终正文、参考文档或生成 Skill 使用同一种语言和文风。它应读起来像目标作品的一部分，而不是外置的分析报告，但事实、未知和结构职责仍要清楚可查。
