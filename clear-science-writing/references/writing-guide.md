# 内容与表达

只在撰写、改写或审校说明与文章时读取。

## 一、内容与表达结构

### 1. 确定要说什么

写作前确定四件事：

- **读者**：谁会读，已知什么，最可能误解什么；
- **目的**：读完后应理解、判断、同意或完成什么；
- **主旨**：一句可独立成立的判断，而非宽泛主题；
- **边界**：必须保留的事实、术语、责任主体、证据和未知。

不要在信息不全时编造背景、数据或来源。以上信息会显著改变文章时，简短说明采用的假设或提出一个关键问题。

### 2. 核对内容边界

区分事实、判断、建议与未知。事实要可核对；判断要说明依据和范围；建议要说清对象、条件与代价；未知要说明它是否影响当前结论。

面对科普、技术、风险或数据内容时，不能用“科学证明”遮盖研究范围、样本、条件或不确定性；也不要制造虚假平衡，把证据权重明显不同的观点写成同等分量。数字至少交代比较对象、单位、时间范围和分母。

需要从原始材料、采访记录、文档或一组文章中提取可写内容时，先阅读 [references/content-structure-extraction.md](content-structure-extraction.md)，产出内容卡和段落地图，再开始起草。提取件默认沿用语料语言；确定 `StyleProfile` 后，再用目标文风重写其面向人的文字。

### 3. 排全文路线

选择能回答读者问题的路线，而不是按材料原来的顺序复述。先写清读者打开文本后最先需要解决的问题、答案准备出现的位置、背景放在哪里，以及结尾必须交付结论、行动、成功标志、失败处理还是叙事余味：

| 任务 | 可选路线 |
| --- | --- |
| 解释现象或机制 | 现状 → 原因 → 结果 → 解决办法或边界 |
| 回答判断或建议 | 结论 → 依据 → 条件/例外 → 下一步 |
| 科普概念 | 熟悉问题 → 核心解释 → 证据如何得出 → 对读者意味着什么 → 已知边界 |
| 操作说明 | 目标 → 前提 → 步骤 → 成功标志 → 失败处理 |
| 方案或决策 | 要解决的问题 → 方案 → 依据 → 代价/风险 → 决定或待确认项 |

为每段写一个动词标签，例如“交代现状”“解释原因”“比较取舍”“给出边界”。相邻两段不得重复完成同一件事；每一段都要让读者比上一段多明白一件必要的事。

不要把任何路线当作固定模板。读者已经知道背景时，直接给结论；读者需要判断结论是否可信时，再补足背景和依据。

### 4. 回应任务，再展开材料

面对材料题、短文题或长文，按此顺序工作：

1. **读限制**：题目要回应什么材料、情境、对象和任务；不把原题改写成另一个熟悉的话题。
2. **定判断**：把宽泛主题压成一句可论证的主张，说明它成立的条件或范围。
3. **选材料**：每个事实、经历或例子都服务于一个理由；例子之后要解释它为什么支持这个判断。
4. **排关系**：段落之间应是递进、因果、转折、并列分工或总分，不是把相关内容逐项堆放。
5. **回读修改**：检查是否真正回应任务，删掉套话和不能支撑主旨的材料。

### 5. 让每个段落完成一个动作

让每段只承担一个中心动作。通常依次完成：

1. 提出本段的判断、问题或转折；
2. 给出原因、过程、证据、例子或对比；
3. 收束本段，必要时引向下一段。

短消息、结论段和清单不必凑成三句。若一句过渡语删掉后意思不变，就删掉；若读者必须自行补足前提才能接受“因此”，就补前提或改掉这个连接词。

短文通常没有篇幅容纳铺垫。先用一句话直接回答，再用一两句给出关键依据或过程，最后写清结果、限制或回扣问题。解释文本时，不能只摘抄原句；要说明“文本写了什么，因此表现或说明了什么”。

### 6. 用句子写出真实关系

用明确的主体和动作写句子：谁做什么、导致什么、依据是什么。术语首次出现时，解释它在当前问题中起什么作用；后文保持同一叫法。避免“进行了优化”“能力得到提升”“相关问题”等没有对象、范围或比较基线的表达。

- 写因果时，交代前提，避免把先后顺序误写成原因；
- 写转折时，说明转折前后分别成立什么，不能只用“但是”制造姿态；
- 写比较时，让对象处于同一维度，并落到差异带来的结果；
- 一个长句只承载一条主干关系；并列成分过多、指代不清或动词缺失时拆开；
- 可以长短交替，但以读者能一次辨认主语、动作和关系为准。
