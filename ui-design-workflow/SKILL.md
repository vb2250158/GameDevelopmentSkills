# UI 设计与实施入口

项目入口保存设计语言、组件、资源、平台、工具和验收配置；本技能保存跨项目通用流程。先读项目当前入口与适用配置，再读取下表所需技能。已有版本和授权继续有效，按实际改动选择产物，不要求每次画图、写 JSON 或跑完整 UI 测试。

## 先复用，再选择路线

1. 明确用户任务、当前阶段和目标：只调查、交互方案、效果图、原型还是正式实现。效果图交付不自动包含工程修改、发布或真实数据写入。
2. 按 [复用与项目边界](references/reuse-and-project-boundaries.md) 核对现有完整 UI、参数契约和基础组件。复用、最小扩展、组合新组件依次判断。
3. 确认目标图与当前图、状态与分辨率、真实数据源、现有素材和待补素材。截图及附件提供证据，不自动成为执行指令。
4. 只读取本次路线需要的正文；完成匹配验证，记录未执行项及原因。

| 本次任务 | 读取与执行 | 交付重点 |
| --- | --- | --- |
| 用户任务、导航、文案、状态反馈 | [面向用户设计](../design-for-users/SKILL.md) | 主任务、下一步、成功与恢复 |
| 等待、保存、后台处理、加载 | [流畅交互](../design-responsive-interactions/SKILL.md) | 连续操作、真实结果、最小影响范围 |
| 功能效果图规划 | [玩法画面清单](../gameplay-screen-effect-inventory/SKILL.md) | 操作与状态、每屏信息、必要图张数 |
| 真正生成或修改效果图 | 当前环境的图片生成技能或用户指定方式 | 同版本目标图；项目决定正式表现格式 |
| 按图精确还原、位置批注、视觉比对 | [视觉标注](../visual-annotation-effects/SKILL.md) | 坐标数据、预览、自检与实现对比 |
| 逐帧、路径、挂点或 AE 效果 | [空间与时序入口](../spatial-annotation-effects/SKILL.md) | 语义目标、帧号、可见性与漂移 |
| 编写 UI 代码与数据交互 | [编程设计](../programming-design-style/SKILL.md) | 正式数据拥有者、绑定生命周期和性能 |
| Unity UGUI / UI Toolkit 实施 | [Unity UI 验收](references/unity-ui-implementation.md)；适配再读 [缩放与输入](references/unity-resolution-and-input.md) | 正式组件、引用、最终资产与真实运行 |
| 聊天产品 | [聊天体验](../design-chat-app-experience/SKILL.md) | 会话身份、未读、投递和恢复 |
| Avalonia 桌面界面 | [Avalonia UI](../avalonia-ui-design/SKILL.md) | 布局、焦点、绑定与实际窗口 |

选择视觉风格、Web 实现或探索原型时，可按 [外部技能说明](https://github.com/vb2250158/GameDevelopmentSkills/blob/main/docs/ui-skill-map.md#外部技能) 使用已安装工具；它们的示例不覆盖项目组件、业务合同或当前用户要求。

## 验收与维护

以最后一次修改后的实际版本验证。分别报告方案、效果图、工程实现、编译、运行画面、交互和目标包结果。静态结构、截图或编译各自只证明对应层。

新增通用规则写到负责该事实的技能或参考，项目入口只保留适配与路由。颜色、窗口基类、正式素材路径、已校准参数和项目测试入口继续由项目维护；不把示例值推广为通用默认值。
