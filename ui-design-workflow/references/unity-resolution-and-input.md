# Unity 缩放、滚动与输入

## 缩放真源

| 系统 | 核对的真实入口 |
| --- | --- |
| UGUI | 生效 Canvas 的 `CanvasScaler`、`uiScaleMode`、`referenceResolution`、`screenMatchMode` 与 `matchWidthOrHeight` |
| UI Toolkit | 目标 `UIDocument` 实际引用的 `PanelSettings`、`scaleMode`、`referenceResolution`、`screenMatchMode` 与 `match` |

按产品适配合同选择模式，不把 UGUI 参数用于 UI Toolkit。再检查局部固定像素、锚点、绝对定位、安全区和脚本覆盖。GameView 工具栏预览倍率只影响编辑器查看，不是业务缩放值。

运行时切换分辨率、比例或窗口尺寸后，当前界面应按合同重排；关闭重开仅验证重建兼容，不能代替自动适配。尺寸变化走现有 UI 回调，避免只在创建时缓存屏幕大小或另设缩放真源。

## 字体与平台

核对 UGUI/TMP 或 UI Toolkit 实际字体和后备设置。用真实中文、数字、长文案验证字形、行高、换行、截断及按钮宽度，拉丁字符可见不证明中文可用。

按项目支持矩阵选择基准、较高像素密度及相关宽高比；支持 4K 时实际覆盖 4K。每种目标核对可读性、点击范围、裁切、列表首尾、运行中重排与最新 Console。固定分辨率和滚轮参数由项目配置，不推广为所有项目默认值。

## 滚轮与触摸

UGUI 调整 `ScrollRect.scrollSensitivity`，UI Toolkit 调整 `ScrollView.mouseWheelScrollSize`；实际入口和版本支持以目标工程为准。值由序列化资源、配置或受控入口维护，以项目高度、Viewport、输入设备和实际手感校准。

需要平滑滚轮时，使用单一待到达位置，连续输入累加到该位置并按帧追赶，钳制内容范围；不要每次滚轮启动独立 Tween 或从当前显示位置重新开始。原生滚动与自定义缓动只有一个位移拥有者，避免双重消费；尺寸变化、拖拽和销毁时处理旧目标与任务。

位移、响应率、停止阈值和调度由可复用入口维护，同用途、密度和设备的列表复用已校准基准。记录实际入口、代码覆盖、方向、有效值和计算依据。连续输入、反向输入、触控板、拖动滚动条、键盘和触摸分别验证；其它输入改变位置时取消旧滚轮目标或从新位置重算，避免回拉。

下一次渲染更新应开始响应；停止后及时收敛，不产生长时间漂移。需要暂停中继续工作的 UI 使用相应 UI 时间源，并处理异常长帧推进量。具体参数通过实际交互校准，不从某个工具的数值推断全项目倍率。

移动端以直接拖拽内容区域为主要入口，检查嵌套滚动、点击与拖动区分、触摸边界、惯性和滚动条。桌面验证滚轮及指针拖拽，目标移动端验证触摸拖拽；首项末项完整可达，滚动不意外触发按钮。静态参数检查不能代替手感和交互验收。

UI Toolkit 优先复用 ScrollView 原生触摸滚动；触摸边界、`touchScrollBehavior`、`scrollDecelerationRate` 与平台滚动条策略按项目确定。仅在已有输入冲突证据时扩展指针处理，并覆盖阈值、捕获、取消与释放。接管 WheelEvent 做缓动时，仅消费一次默认行为；不得原生跳动后再叠加位移。

覆盖慢拖、快速甩动、连续与反向拖拽、嵌套区域、内容不足一屏、窗口重开和尺寸变化；轻触能点击，超过拖拽阈值不误触。短列表记录无需滚动的原因，长列表证明首尾可达且停止后不回到旧目标。
