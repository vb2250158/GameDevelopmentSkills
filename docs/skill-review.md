# 技能整理记录

本轮覆盖仓库正式发布的 14 个技能：原有 10 个，加上从本地已有版本整理的 4 个。按触发、授权、上下文加载、工具依赖、相对引用和完成证据逐项检查；未把维护者的全部个人技能复制到公共仓库。

| 技能 | 处理结果 |
| --- | --- |
| `ai-automation-workflow` | 收窄到表格任务协作；入口按导出、分析、回填、批注、实施加载；截图规则移至参考；明确当前授权、范围与可选分工 |
| `ai-code-security-review` | 由任意路径或网络相关改动触发，收窄为明确安全审查或实际信任边界变化；复用已有授权 |
| `clear-science-writing` | 普通写作与文风提取分开加载；四层分析保留，多 Agent 与评分器按任务选择；语言 Hook 明确为可选用户级工具 |
| `continuous-task-execution` | 新增已有执行规范；不带本机 Hook、扫描根目录或批量改写工具 |
| `current-language-style` | 新增已有语言入口，目标技能与数据改为相对绑定 |
| `direct-evidence-language-style` | 新增已有通用中文风格及运行档案；不含私人语料 |
| `github-pull-workflow` | 保留现有差异检查、备份、合并与验证流程；没有无条件多 Agent 或固定机器路径 |
| `github-submit-workflow` | 同步本地发布核对流程；明确用户请求提供授权，加载技能和填写记录本身不授权发布 |
| `programming-design-review` | 保留已有范围控制、证据与按需报告；与设计规范同级配套 |
| `programming-design-style` | 保留已有数据归属、逻辑表现分离与按需参考；已支持复用核验结果，不要求固定调用样例数量 |
| `project-progress-pm` | 取消默认多 Agent、强制最新模型与固定推理档位；状态和沟通细则按需读取；已授权维护不重复确认 |
| `read-tencent-docs-opendoc` | 保留实际解析与读写合同，命令示例改为实际技能目录；不发布本机账号或凭据 |
| `run-stable-game-automation` | 移除个人工作目录、固定游戏清单、渠道与模拟器政策；保留本轮证据、人工接管、单桌面并发与有界重试合同 |
| `unity-prefab-source-editing` | 新增已有 CLI、脚本与参考；工具位置使用环境变量或当前用户目录，另行说明 Python 依赖 |

既有根目录路径保持不变。已退役技能不重新引入；私有项目资料不进入公开入口、文档、清单或提交说明。具体文件版本以 Git 提交为准。

## 验证与限制

14 个技能的 frontmatter 校验通过，本地 Markdown 引用无失效目标；11 份 JSON 可解析。安装行为验证 10 项通过，覆盖不写入预览、首次安装、重复运行、依赖补齐、冲突保护、无效路径与目录占用。四份相关 PowerShell 脚本语法检查通过，文风标准 HTML 生成后检查通过。

Prefab CLI 使用本地已有解析器通过帮助、文本样例 roundtrip、引用校验、修改预览与原值回读；预览后样例未被改写。未自动在其它电脑安装软件、连接 Unity、登录在线表格或运行游戏。在线服务、目标电脑 Agent 发现与真实游戏行为须在各自环境验证。

未测量响应时间或 token 收益；文档拆分只能证明加载入口发生变化，不能用于承诺固定提速。

## 指令入口维护补充

新增 `agent-instruction-maintenance`，当前公开清单为 15 项。该技能说明入口预算、按任务拆分、规则迁移映射、加载验证和发布回读，并提供不含私有项目资料的全局入口模板。全局语言、文档读者、沟通、设计和持续执行细则分别由对应现有技能维护；短答不会额外加载文档读者与长汇报规则。
