# 多帧与语义路径标注

1. 定义用户指定的具体部位或目标点、帧率、帧号/时间基准及可见性规则。导出覆盖旋转、遮挡、方向变化和裁切的清晰帧。
2. 多模态逐帧或按约定关键帧判断语义目标，记录 `frame`、`visible`、`x`、`y`、`confidence`、`visualNotes` 与坐标来源。不可见时保留不可见状态，不编造可见位置。
3. 画出目标点、帧号与路径方向并查看预览。点落在相邻部位、背景或旧特效上时先重标，不能用调粒子参数弥补。
4. 采样通过后再插值或生成 AE keyframe、Unity 路径、遮罩及动画。可信骨骼、插槽或 Transform 可作为运动源，但仍需核对目标和坐标变换。
5. 比较渲染前、中、后及遮挡边界，记录空间漂移与时间偏移，修正后重新验证相关范围。

用户要求逐帧人工确认时，少量关键帧插值不能冒充逐帧采样。算法候选与最终点分开记录，颜色、alpha、轮廓或最近像素不能独自证明语义部位。

大量帧按连续区间处理。当前用户或适用流程明确要求多 Agent 时分配独立帧段，统一 schema，由协调者合并；否则顺序或批量处理。合并检查帧号连续、可见性边界、缺点、跳点和区间接缝，只重做有具体问题的范围。
