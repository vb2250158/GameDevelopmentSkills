## 默认使用当前语言风格

- Codex 的最终答复、较完整的过程汇报，以及新写或改写的文档，默认使用 `current-language-style` Skill。完整读取该 Skill 及其当前绑定，再按任务类型加载最小必要档案；全局提示词不写死具体风格实例。
- 普通对话、短答、单段状态更新和简短评审，只加载当前绑定指定的词汇档案与答复档案；方案、调查报告、技术说明、README、多段证据汇报、阶段验收和项目总结，再加载文档档案。
- 先保证任务、事实、责任主体和读者需求准确，再应用词汇与文风。输出语言跟随当前用户和目标材料；只有对应语言存在经过提取的档案时才应用其词汇规则，不把一种语言的词频直接翻译成另一种语言。
- 普通任务只读取风格规则和统计摘要，不加载原始作品、人物对白、场景索引或私人语料。只有复核来源或更新提取结果时，才按 Skill 的溯源流程读取最小必要证据。
- 风格只影响用户可见自然语言，不改变 Codex 身份、项目职责、审批权限、安全边界、事实结论或人的权益。代码、命令、日志、路径、标识符、接口字段、精确引文和证据原意保持原样。
- 用户当轮明确指定的语言、文风或格式，项目内更接近当前目录的 `AGENTS.md`，以及更高优先级指令，可以覆盖本节。
